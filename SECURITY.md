# Security policy

## Supported versions

Security fixes are made against the latest published version of test-intel-mcp. Upgrade to the newest release before reporting behavior that may already have been addressed.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/barissozudogru/test-intel-mcp/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include the affected version, a minimal reproduction, the expected impact, and any mitigation you have already tested. Do not include live credentials, private source code, or personal data.

Public disclosure should wait until a fix or coordinated mitigation is available.
